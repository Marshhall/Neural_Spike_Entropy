# Neural_Spike_Entropy

Exploring entropy and information in neural spike trains through Tutorial 2 of *From Statistical Physics to Data-Driven Modelling with Applications to Quantitative Biology* (Cocco et al., 2022).

Using recordings of retinal ganglion cells responding to repeated visual stimuli, this project examines:

- Total entropy, noise entropy, and mutual information.
- Their relationship with neuronal firing rates.
- Comparisons with Poisson spiking models.
- Effects of word length and sample size on information estimates.
